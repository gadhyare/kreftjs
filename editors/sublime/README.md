# Kreft for Sublime Text

Syntax for `.kreft` / `.kreftjs` files (extends Sublime's built-in HTML syntax, so `<script>` is JavaScript and `<style>` is CSS), comment toggling, and snippets.

Install: copy this folder to `Packages/Kreft` (Preferences > Browse Packages...) and reopen a `.kreft` file.

Limit: Kreft-only keywords (`state`, `action`, ...) get no special color yet.
