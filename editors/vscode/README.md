# Kreft for VS Code

Colors, bracket matching, comments (Ctrl+/), folding and snippets for `.kreft` files.

Install from a Kreft project or the Kreft folder:

```bash
kreftjs vscode
```

Then restart VS Code. Type `kreftjs` in an empty `.kreft` file for a starter component, or `state`, `action`, `for`, `kreft-wait` …

Files with the older `.kreftjs` extension get the same colors.
