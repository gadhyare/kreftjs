# Kreft for VS Code

Colors, bracket matching, comments (Ctrl+/), folding and snippets for `.kreftjs` files.

Install from a Kreft project or the Kreft folder:

```bash
kreftjs vscode
```

Then restart VS Code. Type `kreftjs` in an empty `.kreftjs` file for a starter component, or `state`, `action`, `for`, `kreft-wait` …

Files from older projects (`.kreft`, and `.som` from Som.js) get the same colors. Both `s-` and `k-` directives, and both `<som-…>` and `<kreft-…>` tags, are highlighted.
