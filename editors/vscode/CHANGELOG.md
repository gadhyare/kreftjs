# Changelog

## 2.4.0
- Emmet abbreviations in `.kreft` files: HTML in `<view>` (`ul>li*3`), CSS in `<style>` (`m10`, `df`).

## 2.3.0
- Syntax colors for `.kreft` (and legacy `.kreftjs`) files, including embedded HTML, CSS and JavaScript.
- Bracket matching, auto-closing pairs, comments (Ctrl+/) and folding for `<view>` and `<style>`.
- Document formatter and snippets (`kreftjs`, `state`, `action`, `for`, `kreft-wait`, ...).
